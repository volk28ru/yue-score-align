# yue-score-align

Визуальный редактор партитур вокальной линии YuE2. Проект решает задачу
сопоставления партитуры ABC (Score) и текста песни (Lyrics): строит
таймлайн нот, позволяет редактировать вокальную и инструментальную партии
в браузере и экспортирует результат в виде ABC-строки, готовой для YuE2.

## Назначение

Модель YuE2 генерирует вокал из партитуры ABC и текста, в котором слоги
выровнены по нотам. Ручная подготовка такой партитуры трудоёмка: необходимо
контролировать длительности, паузы, секции и распределение слогов.
`yue-score-align` визуализирует партитуру в виде таймлайна и предоставляет
инструменты правки с мгновенным пересчётом выравнивания.

## Возможности

- Разбор ABC-нотации с двумя голосами (Vocal + Ins), секциями
  (`% intro`, `% verse`, …), встроенными сменами размера (`M:2/4`),
  паузами `z`/`Z` и связями `-`.
- Автоматическое выравнивание слогов текста по нотам вокала, включая
  мелизмы (связки), с диагностикой расхождений.
- Таймлайн с неподвижной тактовой сеткой, линейкой тактов, полосами секций
  и двумя дорожками (Vocal и Ins) на общей временной оси.
- Две карты: исходная (только просмотр) и редактируемая — для наглядного
  сравнения внесённых изменений.
- Редактирование: высота (полутоны), длительность, связи, вставка и удаление
  нот и пауз, перемещение блоков перетаскиванием, изменение длительности
  мышью (resize).
- Импорт Score и Lyrics из файлов.
- Экспорт в ABC с пересбором метрики по неподвижной сетке; копирование в
  буфер обмена и сохранение в файл `.abc`.
- Компактный интерфейс без прокрутки страницы: все органы управления
  помещаются на одном экране.

## Установка и запуск

Требования: Python 3.10+, современный браузер.
Внешние зависимости отсутствуют (используется только стандартная библиотека).

1. Открыть терминал в каталоге проекта:
   `cd /run/media/volk/games/yue2/yue-score-align`
2. Запустить сервер:
   `python server.py`
3. Открыть в браузере: `http://localhost:8090`

Остановка сервера — `Ctrl+C` в терминале.

## Интерфейс и рабочий процесс

### Верхняя панель
- «Импорт ABC из файла» / «Импорт текста из файла» — загрузка исходных
  данных в поля Score (ABC) и Lyrics.
- «Построить таймлайн» — запрос к серверу: разбор партитуры, выравнивание
  слогов, построение обеих карт.

### Карты
- «Исходная карта (просмотр)» — снимок партитуры на момент построения;
  нереактивна (клики и перетаскивание отключены), служит эталоном.
- «Редактируемая карта» — рабочая область: дорожка Vocal (зелёные блоки
  со слогами) и дорожка Ins (синие блоки); тишина отображается блоками `S`.
- Общая неподвижная тактовая сетка: границы тактов не перемещаются при
  правках — содержимое сдвигается относительно них.

### Редактирование (редактируемая карта)
- Клик по блоку — выделение (оранжевая рамка).
- Панель инструментов:
  - «− полутон» / «+ полутон» — транспонирование выделенной ноты;
  - «− длит.» / «+ длит.» — изменение длительности с шагом 1/16;
  - «связь ~» — переключение лиги (мелизма) у ноты;
  - «+ нота» / «+ пауза» — вставка события после выделенного;
  - «удалить» — удаление выделенного события; последующее содержимое
    сдвигается влево по неподвижной сетке.
- Перетаскивание блока — перемещение события в пределах его секции.
- Тяга за правый край блока — изменение длительности с привязкой к шагам 1/16.

### Блок экспорта (внизу страницы)
- «Экспорт ABC» (акцентная кнопка) — пересборка партитуры с пересчётом
  метрики и вывод строки в поле ниже.
- «Копировать» — копирование строки в буфер обмена.
- «Сохранить .abc» — скачивание файла `yue-score.abc`.

Строка диагностики под панелью инструментов: число слогов без нот и
нот без слога.

## Поддерживаемый формат ABC

Поля заголовка: `X:`, `T:`, `M:`, `L:`, `Q:`, `K:`.
- Голоса: `V: Vocal …`, `V: Ins …` (имена берутся из `name="…"`).
- Секции: строки, начинающиеся с `%`, после заголовка
  (`% intro`, `% verse`, `% chorus`, …).
- Встроенная смена размера: `M:2/4` внутри строки голоса.
- Ноты: буквы с альтерациями (`^`, `_`) и октавными метками (`,`, `'`,
  регистр буквы); длительности — в долях базового шага `L:`.
- Паузы: `z` (внутритактовая), `Z` (многотактовая).
- Связь: `-` после ноты.
- Тактовая черта: `|`.

Базовый шаг: `L:` (как правило 1/16). В этих шагах исчисляются все
длительности и сетка таймлайна.

## API сервера

### POST /api/align
Запрос: `{ "score": "<текст ABC>", "lyrics": "<текст песни>" }`.
Ответ:
- `unit` — базовый шаг (например `"1/16"`);
- `vocal_id` — имя вокального голоса;
- `blocks` — массив блоков `{ voice, section, section_label, inline, events }`;
  событие: `{ kind, name, pitch, dur, tie, rest_case, section, letter,
  oct_marks, acc, syllable }`;
- `leftover` — слоги, не получившие ноты;
- `notes_without_syllable`, `sections`.

### POST /api/export
Запрос: `{ "score": "<текст ABC>", "blocks": <блоки после правки> }`.
Ответ: `{ "abc": "<готовая ABC-строка>" }`.

Статика: `GET /` → `web/index.html`, далее `app.js`, `style.css`.

## Семантика редактирования

- Таймлайн строится по неподвижной тактовой сетке: такт k начинается с шага
  k × (шагов в такте); смена размера (`M:`) меняет ширину такта с
  соответствующей границы.
- Удаление или укорочение события сдвигает всё последующее содержимое влево
  относительно неподвижной сетки (поведение секвенсора).
- При экспорте тактовые черты вокальной партии пересчитываются («rebar»):
  каждый такт вновь содержит ровно шагов в такте; многотактовые паузы `Z`
  разворачиваются в потактовые паузы `z` с чертами; неполный последний такт
  блока закрывается чертой.
- Инструментальная партия экспортируется без изменений.

## Известные ограничения

- Правки рекомендованы для вокальной партии; правки дорожки Ins сохраняются,
  но их метрика при экспорте не пересобирается.
- Перемещение блока перетаскиванием ограничено пределами одной секции.
- Выравнивание слогов пересчитывается при каждой правке: мелизм (нота со
  связью) наследует слог первой ноты цепочки.

## Разработка и расширение

- Клиентская логика сосредоточена в `web/app.js`:
  `buildContentFrom` (блоки → блоки таймлайна), `buildGridFrom` (тактовая
  сетка), `renderTimeline` (отрисовка карты), `rebarredBlocks` (пересбор
  метрики при экспорте).
- Новая операция редактирования добавляется расширением функции `act(a)`
  и кнопкой с атрибутом `data-act` в `web/index.html`.
- Масштаб шага по горизонтали задаётся константой `STEP_PX` в `web/app.js`.

## Назначение в рабочем процессе YuE2

Полученная строка ABC передаётся модели YuE2 совместно с текстом песни;
редактор гарантирует метрическую корректность партитуры и точное
соответствие слогов нотам, что повышает стабильность генерации вокала.

## Аудио-предпросмотр

- Кнопки «▶ Вокал», «▶ Вокал+Ins», «■ Стоп» в верхней панели.
- Синтез через Web Audio API: вокал — осциллятор «triangle», инструмент —
  приглушённый «sawtooth»; темп берётся из поля `Q:` партитуры.
- Связанные ноты (лиги) звучат как один непрерывный тон.
- Во время воспроизведения по обеим картам движется плейхед с автопрокруткой.

## Сессии редактирования (JSON)

- «Сохранить сессию» — выгрузка файла `yue-session.json` с полным состоянием:
  тексты Score и Lyrics, базовый шаг, имя вокального голоса, список слогов
  и блоки с правками.
- «Загрузить сессию» — восстановление состояния из файла без запроса к
  серверу: пересчитываются слоги и перерисовываются обе карты; исходная
  карта становится снимком загруженного состояния.
- Сессия позволяет продолжить работу после перезапуска браузера или
  перенести редактирование на другую машину.
